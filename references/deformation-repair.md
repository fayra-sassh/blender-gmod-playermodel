# 手、附件和裙摆：按部件修复，不改标准骨架

用于用户报告手部畸形、头巾随手臂飞起、腰饰错绑、抬腿或跳跃裙子穿模。先锁定出问题的实际版本和动作，再做局部工作副本。不要仅凭一张截图宣称已确定所有原因。第一人称 c_hands 另读 [第一人称手模制作](first-person-hands.md)，不能直接沿用第三人称骨架。

制作完成默认交给用户自行验证。下面的动作列是用户自检或用户明确委托诊断时的候选范围，不是 agent 必须执行的压力测试、渲染或游戏验收流程。只做修复所需的源数据、权重、导出和编译错误检查。

## 修复前必须记录

- 标准骨架名称、父级和静止矩阵；源网格顶点/三角数量、UV、材质与原始坐标。
- 受影响的对象、顶点组、连通片及修改器；原始模型/拟合前几何与当前版本对应关系。
- 用途分区：皮肤、手、袖子、头巾、腰带、裙摆、腿环、吊饰。不以材质槽号作为唯一分类条件。

共用一个 atlas 的腿环、手环、腰饰可能是不同附件。拟合后的袖子可能落在裙摆的高度区间，所以分区优先用原始参考坐标和拓扑，不在每次变形后重新按一个 Z 阈值分类。无法可靠匹配时，保留显式选择/区域表，先人工核对。

## 各区域的策略与检查

| 症状/部件 | 修复策略 | 用户自检或受托诊断 |
|---|---|---|
| 手掌/手指扭曲 | 按肩、肘、腕和手指关节中心与局部轴拟合；逐条指链校对左右、分段及指尖权重 | 开手、握拳、持械，腕部与袖口接缝 |
| 头巾/头部附件跟手 | 按实际连接位置重建头/颈/上躯干的合理梯度，清除非预期臂手权重 | 双臂举起、转头、低头，不因举手整片飞起 |
| 腰带/上腰饰 | 主要跟随 pelvis/下躯干，腰际平滑过渡；悬挂片与硬饰分别处理 | 抬腿、弯腰、跳跃，不被远端手脚拉扯 |
| 腿环/贴身附件 | 从对应身体表面取得局部插值权重，限制最近面必须在正确腿/区域 | 随腿弯曲，不混入 skirt 或对侧腿组 |
| 裙摆/长飘带 | 按前、后、侧及连接高度分别设计骨盆/大腿等梯度，必要时受控膝部跟随 | 左右高抬腿、收腿跳跃、深蹲和大步跑 |

不能把每个顶点按原骨与目标骨的位置差简单加权平移，指链与腕部尤其容易变形；也不能对整片头巾/衣物运行手臂拟合。拟合、重新绑定和权重转移是不同步骤。

## 裙摆穿模的迭代

1. 保持腰部连接稳定，把裙片分区。裙摆离腿很近却几乎只跟 pelvis 时，抬腿容易穿过；但全裙刚性跟大腿会抬翻前片、撕扯腰部。用高度和片区的渐变权重折中，不统一一个比例。
2. 前片需要跟随抬腿，后片与侧片分别处理。必要时少量跟随同侧膝/小腿仅用于明确下摆区域；不能全局禁止或全局加入 calf。记录允许骨、区域与影响上限，核对导出的实际权重。
3. 贴身附件可按对应身体三角形做重心插值权重转移；最近面距离、侧别和语义区域必须受限，避免前后面/另一条腿误配。
4. 必要时局部增加合理间隙，按模型单位记录幅度并核对轮廓。不要整体膨胀、删腿或任意改拓扑来隐藏穿模；会改变外观的方案先确认范围。默认不是实现真实布料物理。
5. 每轮只改明确区域，验证标准骨架、皮肤/手/头、UV、材质及不在范围内的顶点没有变化。不要在已经变形的版本上累计重复位移。
6. 保留上一轮和最终版本。优先同时降低几种目标动作的穿插，不为一个动作牺牲其他动作或静态外观。

具体顶点编号、坐标阈值和比例必须重新从该模型计算；妮露一次修复的数值不是其他人物的模板。

## 用户明确委托时的动作诊断和测量边界

默认不执行此节。用户明确要求预览或委托动作诊断时，先覆盖用户报告的动作，按该范围选用 rest、左右抬腿、收腿跳跃、蹲下、走跑或举手等对照姿态，不自动扩展为全套测试。优先读取实际动画姿态，在 Blender 手工摆的姿势仅是有限诊断证据。

临时测试保存每个骨的原 `matrix_basis`、原动画/action 状态、模式、帧、相机和修改过的渲染/可见性设置，在 `try/finally` 中完整恢复。恢复后重新读取确认，保存干净的发布副本；不要把测试姿势、临时遮挡或摄像机改动误保存为最终绑定。

可对限定的身体与衣物表面检测实际边/三角交点，并输出部件、数量和位置。BVH 包围盒 overlap 只是候选对；非封闭/有缝身体网格的最近点法线符号也不能可靠判定内外。允许的贴合接触需结合图像和位置分辨，少量或零计数不代表所有动画都不穿模。

修复完成后交付制作产物、备份及简短用户自检建议，不把前/侧/后动作预览或 GMod 验收作为默认完成条件。用户自行重启并检查相关动作；只有他们明确委托才执行对应检查。报告实际做过的制作或诊断范围、剩余限制，不写“永不穿模”或“游戏实测通过”。
